# Dhandha Dheko – AI Business Operating System
### Public Case Study

**Dhandha Dheko** is an AI-powered Business Operating System being built for Indian SMEs.  
It helps businesses manage daily operations and uses AI agents + automation to surface growth opportunities, cost savings, and high-ticket commercial deals.

> This repository is a **public case study**.  
> The actual source code remains private.

---

## 1. Problem

Most small and medium businesses in India still run on:
- Fragmented tools (Excel, WhatsApp, Tally, separate billing apps)
- Manual decision making
- Limited visibility into true business health
- No intelligent system that connects operations data to commercial opportunities

Existing software either focuses only on accounting **or** only on CRM.  
Very few systems try to turn operational data into **actionable growth and deal opportunities**.

---

## 2. Solution Overview

Dhandha Dheko combines:

1. **Core Business Operations Platform**
   - Dashboard
   - Customers & Masters
   - Billing & Invoices
   - Inventory & Stock
   - Expenses
   - GST
   - Reports
   - Company & Financial Year management

2. **AI Business Intelligence Layer**
   - Business Health Score
   - AI Insights Feed
   - AI Business Coach
   - AI Profit Coach
   - Opportunity detection (Profit, Cost Saving, Growth Ideas)

3. **Multi-Agent + n8n Orchestration System**
   - Specialist agents (Sales, Finance, Inventory, Operations, Opportunity)
   - Automated signal aggregation
   - Trade & Sourcing Matchmaker
   - Verification & risk layer
   - Two monetizable fulfilment paths (Import/Sourcing deals + Machinery deals)

## 4. System Architecture

### High-Level Architecture (n8n Integrated)

![Architecture Diagram](./screenshots/architecture-final.png)

**Dhandha Dheko – Final n8n Integrated Architecture**

#### Layer Breakdown

| Layer | Purpose |
|-------|---------|
| **1. Input Sources** | Operational data, inventory, user inputs, machinery signals |
| **2. Event & Orchestration (n8n)** | Central automation engine – data collection, routing, triggering agents |
| **3. Business Intelligence Agents** | Specialist agents for Sales, Finance, Inventory, Operations + Opportunity Intel |
| **4. Signal Aggregation & Matchmaking** | n8n aggregates signals → Trade & Sourcing Intel Agent (Matchmaker) |
| **5. Verification & Quality Layer** | Verification Agent + deterministic risk checks before any action |
| **6. Output / Actions** | Email, Phone workflows, Supabase updates |

#### Two Monetizable Paths

**Path A – Import / Sourcing Deal (Direct Sourcing Arm)**  
Detects savings potential → Calculates landed cost → Creates trade offer → Captures commission / bulk margin

**Path B – Machinery Sales Deal (Capacity Expansion Arm)**  
Detects bottlenecks → Matches technical specs (OEM database) → Calculates ROI → Facilitates machinery deals

Both paths lead to **Closed Deal Fulfilment**.

## 5. Technology Stack

| Area | Technology |
|------|------------|
| Frontend | Modern web + mobile interface (Lovable + custom components) |
| Backend & Database | Supabase (PostgreSQL, Auth, Row Level Security) |
| Automation | n8n (workflows, webhooks, orchestration) |
| AI Layer | LLM-powered agents + prompt engineering |
| Architecture Style | Multi-tenant, event-driven, multi-agent |
| Version Control | GitHub |

**Key Design Decisions**
- Multi-tenant with Row Level Security (RLS)
- Automation-first approach using n8n
- AI agents focused on analysis and opportunity detection (not just chat)
- Clear separation between operational data and commercial opportunity engine
